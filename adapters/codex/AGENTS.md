# Railsmith Codex Adapter

Read `core/AGENTS.md` before non-trivial agent-assisted work.

Use skills from `skills/` when they match the task:

- `rails-architecture`
- `rails-code-review`
- `rails-controller`
- `rails-service-object`
- `rails-pr-workflow`
- `maintainer-voice`

Repo-local instructions override this adapter. Keep Railsmith public-safe and do not add private project details to the shared repo.

If the user asks to adopt or sync Railsmith, follow the Harness Bootstrap Directive in the repository root `AGENTS.md`. Configure Codex directly; do not require the user to run `scripts/adopt`.
