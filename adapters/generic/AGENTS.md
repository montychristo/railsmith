# Railsmith Generic Adapter

Use this for tools that read `AGENTS.md` but do not have a more specific adapter.

Read `core/AGENTS.md`, then the relevant project space, then repo-local guidance.

If the user asks to adopt or sync Railsmith, follow the Harness Bootstrap Directive in the repository root `AGENTS.md`. Configure the generic `AGENTS.md` target directly; do not require the user to run `scripts/adopt`.
