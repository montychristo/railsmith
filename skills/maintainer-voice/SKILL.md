# Maintainer Voice

Use this for writing in the selected maintainer voice.

Read:

- `../../docs/voice.md`
- `../../profiles/chris/voice.md` when using the Chris profile

Defaults:

- Direct, pragmatic, conversational.
- Short by default.
- Clear about uncertainty.
- Action-oriented.
- Technical enough to be useful, plain enough to be readable.
- Avoid corporate phrasing, fake certainty, and over-polished prose.
